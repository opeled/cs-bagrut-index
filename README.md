# אינדקס שאלות בגרות במדעי המחשב

אתר סטטי בעברית המבוסס על טבלה עם תגיות נושא. מדגם ראשוני של 13 שאלות מתוך שאלון 899381 בקיץ 2022, 2023 ו־2024.

עמודות: נושא השאלה, שאלון ומועד, עמוד, מספר שאלה, קישור. שאלה נשמרת כרשומה אחת עם כמה תגיות. מספרי העמודים והשאלות נבדקו מול קובצי משרד החינוך ב־30.10.2026. נוסחי Java ו־C# בעלי עמודים שונים מקבלים קישורים נפרדים. הקפיצה לעמוד תלויה במציג ה־PDF.

האתר מקשר לשאלונים במשרד החינוך; קובצי השאלונים עצמם אינם נכללים במאגר. הסיווג והתיאורים הם כלי עזר עצמאי, ולא פרסום רשמי של משרד החינוך.

`index.html` הוא האתר העצמאי המוכן לפרסום. `src/table.html` הוא מקור התצוגה הניתן לעריכה. אין תהליך התקנת חבילות או שירות שרת נדרש להפעלת האתר.

## פרסום

GitHub Pages מתוך ענף `main`, תיקיית השורש `/`.
