# אינדקס שאלות בגרות במדעי המחשב

[פתיחת האתר](https://opeled.github.io/cs-bagrut-index/)

770 רשומות שאלות מתוך 56 שאלונים שונים בעברית, בשנים 2011–2026, עם 23 תגיות נושא. הטבלה מסודרת לפי נושא, שאלון ומועד, עמוד תחילת השאלה בקובץ PDF, מספר שאלה וקישור. אפשר לסנן בלחיצה על תגית ולחפש שנה, שאלון או נושא. כל התוצאות מוצגות בגלילה רציפה.

## היקף ומקורות

המאגר מבוסס על 62 רשומות שהחזיר מאגר משרד החינוך עבור מקצוע 899 ושפה עברית. רשומות שמפנות לאותו שאלון אוחדו. שאלות בעלות מספרים נפרדים נשמרות בנפרד גם כאשר הן נוסחי שפה חלופיים; שאלה אחת הכוללת כמה סעיפים נשמרת כרשומה אחת. אותו תוכן המופיע בשאלונים שונים נשמר בכל שאלון.

58 קובצי מקור הורדו בהצלחה, ובהם 55 מסמכים בעלי תוכן שונה. שני קישורים שבורים מ־2017 תואמים לשאלונים הזמינים תחת הסמלים המקבילים המופיעים בכריכה. שני הקישורים השבורים מ־2018 מפנים לאותו שאלון 602/899222; עבורו נעשה שימוש בעותק סרוק בן 15 עמודים המקושר בטבלה ומסומן כעותק סרוק. כך מתקבלים 56 שאלונים שונים. ההיקף מתייחס לרשומות שהחזיר המאגר, ואינו טענה שכל בחינה היסטורית קיימת במאגר.

מספרי השאלות ועמודי ההתחלה הוצלבו עם טקסט ה־PDF ומיקום מספרי השאלות בעמוד. סתירות בין דרכי החילוץ נבדקו ותוקנו. השאלון הסרוק מ־2018 נבדק חזותית בכל עמודיו. 30 שאלות כוללות קישורים נפרדים לעמודי Java ו־C# שזוהו בכותרות המקור. יתר הקישורים מובילים לתחילת השאלה. הקפיצה לעמוד תלויה במציג ה־PDF.

התיוג מבוסס על תוכן השאלה והקוד: תגיות מציינות דרישות מהותיות, ולא כל לולאה או משתנה שמופיעים בקוד. פעולות ופירוק לבעיות משנה נכללים ביסודות התכנות. מחסנית באוטומט מחסנית נכללת במודלים חישוביים, ולא מתויגת אוטומטית כמחסנית תכנותית. הסיווג הוא כלי עזר עצמאי ואינו סיווג רשמי של משרד החינוך.

קובצי השאלונים וטקסט השאלות אינם נכללים במאגר זה; נשמרים רק מטא־נתונים, תגיות וקישורים למקורות.

## קבצים ועדכון

- `src/catalog.json`: כל רשומות השאלות, המקורות והתגיות.
- `src/table.html`: תצוגת הטבלה.
- `src/build.py`: שילוב הנתונים והתצוגה לקובץ עצמאי.
- `src/provenance.json`: רשימת השאלונים וכיסוי רשומות המקור.
- `index.html`: האתר המוכן לפרסום, ללא תלות בספריות חיצוניות.

לבנייה מחדש: `python3 src/build.py`.

GitHub Pages מפרסם מענף `main`, תיקיית השורש. המאגר נשמר בארכיון בין עדכונים כדי לחסום שינויים, בקשות משיכה ותגובות. בזמן פרסום עדכון יש לפתוח אותו זמנית, להמתין להצלחת הפרסום ולהחזירו לארכיון.

## בדיקת מדגם נוספת

ב־30.10.2026 נבדקו 130 מתוך 800 קישורי השאלות (16.25%), עבור 100 שאלות מכל 56 השאלונים. כל הקבצים הורדו מחדש, עמודי היעד וכותרות השאלות נבדקו חזותית, והתוכן והקוד נבדקו מול התגיות. לא נמצאו במדגם קישורים שבורים, מספרי שאלות שגויים או עמודי התחלה שגויים. נוספו ארבע תגיות חסרות בארבע שאלות. פירוט הבחירה, המקורות, התוצאות והתיקונים נמצא ב־[דוח הבדיקה](src/audits/2026-10-30.json). זו בדיקת מדגם; תוצאותיה אינן אימות נוסף של השאלות שלא נבחרו.
